# 🏠 FixAI — Smart Hostel Complaint Management Platform

**FixAI** is a smart hostel complaint management platform designed to make maintenance reporting, assignment, tracking, service-provider management, and payment handling easier and more organized.

🎯 **Goal:** Make hostel maintenance simple, transparent, and trackable for students, administrators, and service providers.

---

## 🚀 Why FixAI?

In many hostels, students report maintenance issues manually or have to contact different people for different problems.

This can create problems such as:

* ❌ No proper complaint tracking
* ❌ Difficulty knowing who is handling the complaint
* ❌ Delayed maintenance
* ❌ No clear service-provider assignment
* ❌ Difficulty tracking service charges
* ❌ No centralized payment workflow

💡 **FixAI brings the complete complaint-resolution process into one platform.**

# 💡 How FixAI Works

### 1️⃣ Student Raises a Complaint

The student logs into FixAI and submits a hostel maintenance complaint.

The student can provide:

* 📝 Complaint title
* 📄 Problem description
* 🏷️ Category
* 🔖 Subcategory
* 🏠 Hostel details
* 🚪 Room details
* 📷 Supporting information, if applicable

---

### 2️⃣ 🤖 AI Complaint Analysis

FixAI can use AI assistance to analyze the complaint and help identify:

* 🔎 Complaint category
* 🔧 Type of maintenance issue
* ⚡ Priority
* 📊 Relevant complaint information

This helps administrators understand and process complaints more efficiently.

---

### 3️⃣ 👨‍💼 Admin / Warden Reviews the Complaint

The admin/warden can:

* 👀 View student complaints
* 📄 Check complete complaint details
* 🔍 Review complaint status
* 🔧 Select an appropriate service provider
* 📊 Monitor complaint progress

---

### 4️⃣ 🔧 Service Provider Assignment

The admin assigns the complaint to a suitable service provider.

Examples:

* ⚡ Electrician
* 🚰 Plumber
* 🪚 Carpenter
* 🧱 Mason
* 🧹 Cleaner
* 🌐 Internet Technician
* 🛠️ Other Service Provider

If no provider has been assigned:

```text
⚠️ Service Provider: Unassigned
```

After assignment:

```text
👨‍🔧 Service Provider: Assigned
```

---

### 5️⃣ 👨‍🔧 Service Provider Handles the Work

The assigned service provider can:

* 📋 View assigned complaints
* ✅ Accept the work
* 💰 Set professional charges
* 🔄 Update work status
* 🛠️ Complete the maintenance work
* 👤 Manage their profile

# 💰 Payment & FixAI Commission

FixAI includes a payment workflow for completed service requests.

### Payment Flow

```text
🛠️ Service Completed
        ↓
💰 Service Provider Sets Fee
        ↓
👨‍💼 Admin Reviews Payment
        ↓
📱 Payment through FixAI QR
        ↓
💳 Payment Completed
        ↓
        ┌──────────────────┐
        │  Total Fee 100%  │
        └────────┬─────────┘
                 ↓
        ┌────────┴─────────┐
        ↓                  ↓
   🏢 FixAI             👨‍🔧 Provider
    20%                    80%
Commission              Earnings
```

### Example

If the service fee is **₹1,000**:

| Payment Distribution         | Amount |
| ---------------------------- | -----: |
| 🏢 FixAI Commission — 20%    |   ₹200 |
| 👨‍🔧 Service Provider — 80% |   ₹800 |
| 💰 Total                     | ₹1,000 |

The payment QR is provided by **FixAI**, and the payment flow is managed through the admin/payment section.

# ▶️ Running the Project Locally

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/NAVEENMAHAWAR/FixAi-Trio.git
```

### 2️⃣ Open the Project

```bash
cd FixAi-Trio
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Configure Environment Variables

Create a `.env` file in the project root.

Add the required configuration such as:

```env
PORT=3000
```

Add your required email/SMTP and owner configuration according to your local setup.

⚠️ **Never upload the `.env` file to GitHub.**

### 5️⃣ Start the Backend

```bash
npm run dev
```

### 6️⃣ Open FixAI

```text
http://localhost:3000
```
